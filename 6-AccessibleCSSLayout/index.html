Start with people

Good design welcomes everyone

A useful website should be clear, comfortable to read, and straightforward to navigate. Accessibility is not an extra layer added at the end; it is part of the design from the beginning.

01

Make it clear

Use descriptive headings, plain language, and predictable navigation.

02

Make it flexible

Let content adapt to different screens, zoom levels, and text sizes.

03

Make it usable

Support keyboard users and provide controls that are easy to activate.

One page, many screens

CSS Grid helps organize a page in two dimensions: rows and columns. Flexbox is ideal for arranging a single row or column of items, such as the navigation links above.

On a wide screen, the page can show several regions side by side. On a tablet, the columns become narrower. On a phone, the layout becomes a single column and the navigation links stack vertically for easier tapping.

Accessibility is practical

Strong color contrast, readable type, visible keyboard focus, semantic HTML, and generous touch targets help more people use a website successfully.

Design for the conditions people actually use—not only the ideal conditions on your own screen.

Quick checks

  • Can you navigate with only a keyboard?
  • Are headings in a logical order?
  • Is the text easy to read?
  • Can links be tapped comfortably?
